# SODA GRAMMATIK KURS

Sophia Deutsch Akademie의 독일어 문법 학습 웹앱입니다. 표지, 목차, Lektion 01–16의 교재, 연습문제(Übung), 추가 연습(Zusatzübung), 복습(Wiederholung), 과제(Hausaufgabe)로 구성돼요.

목차에서 Lektion을 누르면 교재, 연습문제, 추가 연습, 복습, 과제 중 하나를 고르는 페이지(`lektion.html?n=01`)가 열려요.

## 학습 포탈 로그인

이 앱은 소피아 독일어학원 수강생 전용입니다. 모든 페이지가 `<head>` 맨 앞에서 `assets/portal-gate.js`를 불러와, 학습 포탈(SODA-LERNPORTAL)에 로그인했는지 확인합니다.

- 로그인하지 않았으면 학습 포탈 로그인 화면으로 가고, 로그인하면 보던 페이지로 돌아옵니다.
- 한 번의 로그인에서 처음 한 번만 포탈의 학생 파일로 로그인을 확인하고, 그다음 페이지부터는 바로 열립니다.
- 학생이 저장한 답안(localStorage)은 건드리지 않습니다.
- 새 페이지를 추가할 때는 `<head>` 바로 뒤에 `<script src="(상대 경로)assets/portal-gate.js"></script>`를 넣어야 합니다.
- **학습 저장.** 답을 저장하는 페이지(목차, 선택 페이지, 교재, 연습문제, 추가 연습, 과제, 문법 암기장)는 `portal-gate.js` 바로 뒤에서 `<script id="soda-sync" src="/SODA-LERNPORTAL/sync.js"></script>`를 불러옵니다. 학생이 푼 답이 서버에 저장되어 다른 기기에서 포탈에 로그인하면 그대로 이어집니다(SODA-LERNPORTAL README 「학습 기록 자동 저장」). 새 페이지에도 같은 줄을 넣습니다. `autosave.js`보다 먼저 불러와야 합니다.
- 저장소가 공개라서 파일 자체는 주소를 알면 받을 수 있습니다. 이 확인은 화면에서 막는 장치입니다.

## GitHub Pages로 배포하기

1. Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정하고 Save를 누릅니다.
2. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 주소로 접속됩니다.

`.nojekyll` 파일은 숨김 파일이라 폴더에서 안 보일 수 있어요. 웹에서 올릴 때 빠지지 않았는지 확인하세요.

## 교재 페이지 넘겨 보기

교재(`lektionen/lektion-01 … 16.html`)는 핸드폰에서 아래로 길게 밀지 않고 한 페이지씩 넘겨 봅니다. 연습문제·복습·과제·부록은 그대로 스크롤로 봅니다.

- 화면 폭이 820px 이하이고 높이가 440px 이상이면(핸드폰 세로, 작은 태블릿) 페이지 보기로 열립니다. 핸드폰을 가로로 눕혔을 때와 넓은 화면에서는 스크롤 보기로 열립니다.
- 넘기는 방법은 손가락으로 옆으로 밀기(종이가 손가락을 따라 접힙니다), 화면 좌우 가장자리 누르기, 아래 띠의 ‹ › 버튼, 키보드 ← →, 마우스 휠입니다.
- 아래 띠 가운데의 쪽수를 누르면 그 과의 차례가 열립니다. `Aa`를 누르면 글자 크기, 보기 방식(페이지/스크롤), 인쇄를 고릅니다. 스크롤 보기에서는 오른쪽 아래 책 모양 버튼으로 페이지 보기로 바꿉니다. 고른 보기 방식은 기기에 저장됩니다.
- 페이지는 화면 크기와 글자 크기에 맞춰 열 때마다 나눕니다. 문단은 줄 단위로, 표·그림·퀴즈는 덩어리 단위로 나눕니다.
- 문제(`.quiz-block`)는 페이지 보기에서 촘촘하게 놓아 한 페이지에 여러 문제가 들어갑니다. 선지 네 개가 한 줄에 들어가면 한 줄에 4개, 조금 길면 2개씩, 문장처럼 길면 1개씩 놓습니다(글자 폭을 재서 정하므로 선지를 고치면 자동으로 바뀝니다). 풀이는 접은 높이로 재고, 학생이 어떤 페이지에서 답을 누르기 시작하면 그 페이지의 풀이 자리를 잡아 다시 나눕니다. 자리가 모자란 뒤 문제는 다음 페이지로 넘어갑니다.
- 핸드폰 폭(640px 이하)에서만 `pager.js`가 도식을 맞춥니다(컴퓨터 화면은 그대로): 좁은 칸(어순 칸·문장 틀 칸 등)에서 낱말이 중간에 잘리면 같은 줄 칸의 글자를 함께 줄이고, 그림(SVG) 속 글자가 화면에서 11px보다 작아지면 겹치지 않는 만큼만 키웁니다. 표 머리줄은 11.5px보다 작아지지 않게 합니다.
- 문제의 선지는 핸드폰에서 2×2로 놓되, 반 폭에서 한 줄에 다 들어가지 않는 선지가 있으면 한 줄에 하나씩(1×4) 놓습니다.
- 교재의 표가 화면 폭보다 넓으면 `pager.js`가 그 표만 골라 맞춥니다(`data-tf` 1~6단계): 최소 폭과 줄바꿈 금지를 풀고 칸 여백을 줄인 뒤, 그래도 넓으면 글자를 한 단계씩 줄입니다. 스크롤 보기와 페이지 보기 모두 같습니다.
- 격변화표(`table.decl-m`)는 좁은 화면에서도 격(세로)×성(가로) 표 한 장으로 보입니다(스크롤 보기도 같음). 글자와 여백은 교재 파일의 `<style id="decl-responsive">`에서 화면 폭에 맞춰 줄입니다. 칸의 글이 길면 두세 줄로 접히므로, 표를 새로 넣거나 고친 뒤에는 핸드폰 폭에서 한 번 확인하세요. 새 교재 파일에 격변화표를 넣을 때는 다른 과의 이 `<style>` 블록을 그대로 가져옵니다.
- 2과 인칭대명사 표(`table.conj-m.pron-m`)도 핸드폰에서 사람별 카드로 나누지 않고 인칭(세로)×격(가로) 표 한 장으로 보입니다. 다른 동사 변화표(`table.conj-m`)는 그대로 카드로 보입니다. 스타일은 2과 파일의 `<style id="l02-rev">`에 있습니다.
- 한 화면보다 큰 덩어리가 있는 페이지만 그 안에서 위아래로 밀어 봅니다(아래쪽에 화살표가 나타납니다).
- 보던 자리는 과마다 기기에 저장되고, 다시 열면 그 페이지부터 이어집니다. 끝까지 본 과는 처음부터 열립니다.
- 교재 HTML은 고치지 않습니다. 스크롤 보기로 돌아가거나 인쇄할 때는 원래 모양으로 되돌립니다.
- 기기에 저장하는 값(localStorage): `soda-gk-view`(보기 방식, `page` 또는 `scroll`), `soda-gk-pos:lektion-NN`(보던 자리), `soda-gk-pg-hint`(처음 안내를 보여 줬는지), `soda-gk-pg-err`(페이지 보기를 열지 못했을 때의 오류 기록).
- 주소 끝에 `?view=page`, `?view=scroll`, `?view=auto`를 붙여 열면 그 기기의 보기 방식을 바꿉니다(예: `lektionen/lektion-01.html?view=scroll`). `auto`는 저장해 둔 선택을 지우고 화면 크기에 따라 정하게 합니다. 학생이 페이지 보기에서 문제를 겪을 때 `?view=scroll` 주소를 보내 주면 됩니다.
- 어떤 기기에서 페이지 보기가 안 열린다고 하면, 그 기기에서 주소 끝에 `?view=info`를 붙여 열게 하세요(예: `lektionen/lektion-01.html?view=info`). 화면 크기, 고른 보기 방식, 최근 오류와 함께 왜 스크롤로 열렸는지를 적은 확인 화면이 뜹니다. 그 화면을 캡처해 받으면 원인을 알 수 있습니다. 확인 화면의 버튼으로 그 기기의 보기 방식을 바로 바꿀 수도 있습니다.
- 페이지로 나누다가 오류가 나면 스크롤 보기로 되돌리고 "페이지 보기를 열지 못해 스크롤로 보여 드립니다"라는 알림을 잠깐 띄웁니다. 오류 내용은 그 기기에 기록되어 확인 화면에 나옵니다.
- 확인 화면의 "스크립트" 번호는 `assets/pager.js`의 `BUILD` 값입니다. 파일을 고쳐 올릴 때마다 바꿔 두면 기기가 새 파일을 받았는지 알 수 있습니다.
- 시험 운영 스위치: `assets/pager.js` 맨 위의 `var TRIAL`은 평소 `false`입니다. `true`로 바꿔 올리면 `?view=page` 주소로 한 번 연 기기에서만 켜지고 다른 기기에서는 아무 변화가 없습니다(그 기기에서 끌 때는 `?view=auto`). 큰 수정을 학생에게 보이기 전에 먼저 확인할 때 씁니다.

교재를 쓸 때 나누는 자리를 정하고 싶으면 요소에 아래 표시를 붙입니다.

- `data-pg-keep` : 절대 나누지 않음
- `data-pg-avoid` : 되도록 나누지 않음
- `data-pg-head` : 다음 덩어리와 같은 페이지에 둠(제목처럼)
- `data-pg-break` : 이 앞에서 새 페이지를 시작(`section`이나 그 바로 아래 덩어리에 붙입니다)
- `data-pg-fit` : 자리가 조금 모자라면 나누지 않고 살짝 줄여서 넣음(그림·표는 표시 없이도 그렇게 합니다)
- `data-pg-tap` : 이 요소를 누르는 것은 페이지 넘김으로 쓰지 않음(직접 만든 누르는 요소에)

## 연습문제 도전 문제와 답안 저장

연습문제는 A(고르기)·B(맞는 문장)·D(단어 배열)·E(바꿔 쓰기) 영역마다 끝에 도전 문제를 두 개씩 둡니다(2과·11과는 원래 있던 ★ 문제까지 세 개).

- 도전 문제는 그 과의 문법에 앞 과에서 배운 문법을 함께 넣습니다. 1과는 앞 과가 없어서 1과의 규칙 여러 개를 한 문제에 모읍니다.
- 표시: 문제 카드에 `ch` 클래스(`<div class="qc a ch">`)를 붙이고, 문제 문장(`.qt`) 바로 위에 머리줄을 둡니다. `<div class="chh"><span class="chb">도전</span><span class="chm">＋ 2과 3격 동사 · 1과 남성 4격</span></div>` 처럼 함께 나오는 앞 과 문법을 적습니다.
- 페이지 맨 위(제목 아래)의 `.chn` 상자가 도전 표시를 설명하고, 스타일은 각 페이지의 `<style id="sd-ch">`에 있습니다.
- 문제 번호는 페이지 안에서 처음부터 끝까지 이어집니다. 문항을 빼거나 넣으면 번호를 다시 매깁니다.

답안 자동 저장(`assets/autosave.js`)은 문항마다 내용(문제 문장, 선지 글자, 단어 카드, 빈칸이 있는 줄)으로 이름을 붙여 저장합니다(v2). 이름에는 괄호 힌트(`<span class="hn">`)를 넣지 않으므로, 빈칸이나 문제에 힌트를 새로 달거나 고쳐도 학생의 답이 그대로 이어집니다.

- 그래서 문항을 빼거나 새로 넣어도 남은 문항의 답은 그대로 되살아납니다. 문제 문장이나 선지 글자를 고친 문항은 새 문항으로 보고 답을 잇지 않습니다.
- 예전 방식(v1, 순서대로 저장)으로 저장된 답은 각 페이지 맨 끝의 `<script type="application/json" id="sd-prev">`에 적어 둔 예전 문항 배치로 옮겨 옵니다. 2026-11-15 개편 전 배치가 들어 있습니다.
- 연습문제·추가 연습 페이지는 `autosave.js?v=5`, 과제 페이지는 `autosave.js?v=2`를 불러옵니다. `autosave.js`를 고쳐 올릴 때는 16개 연습문제 파일과 16개 추가 연습 파일의 `?v=` 숫자를 함께 올리세요.
- 페이지를 열고 브라우저 콘솔에서 `__sodaUebLayout()`을 실행하면 그 페이지의 문항 배치(문항 이름 목록)를 볼 수 있습니다.
- `autosave.js`가 처음에 답안 복제본을 맞추려고 하는 읽기는 학습 저장(`sync.js`)이 지켜보지 않는 읽기(`SodaSync._get`)로 합니다. 다른 과의 답이 다른 기기에서 바뀌어도 지금 페이지를 새로 불러오지 않게 하려는 것입니다.

교재(`lektionen/lektion-NN.html`)의 확인 문제(`.qi`)는 `assets/quiz-save.js`가 고른 선지를 저장합니다(localStorage `soda-gk-quiz:NN`). 문제 글(`.qq`)로 정한 이름 아래에 저장하므로 문제를 빼거나 순서를 바꿔도 남은 문제의 답은 이어집니다. 각 교재 페이지의 `</body>` 바로 앞, 교재의 문제 스크립트 뒤에서 불러옵니다. 그래야 페이지 보기(`pager.js`)가 페이지를 나누기 전에 답이 되살아납니다.

## 추가 연습

추가 연습(`zusatz/lektionen/lektion-NN.html`)은 연습문제(고르기·맞는 문장·단어 배열·바꿔 쓰기)와 과제에 없는 형식으로 같은 과의 문법을 다시 연습하는 페이지입니다. 모든 문제는 그 과와 앞 과의 문법만 쓰고, 교재·연습문제·과제에 나온 문장은 쓰지 않았습니다.

| 영역 | 형식 | 푸는 방법 |
|---|---|---|
| A 짝 맞추기 | 왼쪽 카드와 오른쪽 카드를 짝지음 | 왼쪽과 오른쪽에서 하나씩 누릅니다(어느 쪽을 먼저 눌러도 됩니다). 일부 세트에는 짝이 없는 틀린 카드가 섞여 있습니다. |
| B 분류하기 | 카드를 기준에 맞는 칸에 넣음 | 카드를 누른 뒤 칸을 누릅니다. 「확인」을 누르면 맞은 카드는 고정되고 틀린 카드는 빨갛게 표시됩니다. |
| C 틀린 곳 찾아 고치기 | 문장에서 틀린 곳을 찾아 고침 | 틀린 낱말을 누르면 고칠 말 세 개가 나옵니다. 어순이 틀린 문장은 자리가 잘못된 낱말 가운데 하나를 누릅니다. |
| D 글에서 찾아 표시하기 | 짧은 글에서 문법 요소를 찾음 | 낱말을 누릅니다. 갈래가 하나면 누를 때마다 표시와 취소가 바뀌고, 둘이면 한 번은 첫째 갈래, 두 번은 둘째 갈래, 세 번은 취소입니다. |
| E 60초 스피드 퀴즈 | 60초 동안 빈칸 고르기 | 「기본」과 「도전」 중 하나를 고릅니다. 키보드 1·2·3으로도 고를 수 있고, 최고 기록이 남습니다. |

- **도전 문제.** A·B·D의 마지막 세트, C의 마지막 두세 문항, E의 「도전」은 그 과의 문법에 앞 과 문법을 함께 넣은 문제입니다. 머리줄의 `도전` 표시 옆에 `＋ 2과 3격 동사`처럼 함께 나오는 앞 과 문법을 적습니다. 1과는 앞 과가 없어서 1과의 규칙 여러 개를 섞습니다.
- **문제 데이터.** 각 페이지 맨 끝의 `<script type="application/json" id="zx-data">`에 A–D 문제가 한 줄에 한 문항씩 들어 있고, E의 문제 묶음은 `assets/zusatz-blitz.js`에 과별로 있습니다. 화면은 `assets/zusatz.js`가 이 데이터로 그리므로 문제를 고칠 때는 HTML 틀은 그대로 두고 데이터만 고칩니다.
  - C: `*낱말*`이 틀린 곳입니다. `o`의 첫째가 정답이고 화면에서는 섞어 보여 줍니다. 낱말 두 개 이상을 한꺼번에 고치면 `c`에 고친 문장 전체를 적습니다.
  - D: `[낱말]`은 첫째 갈래, `{낱말}`은 둘째 갈래의 정답입니다.
  - E: `[문장, [정답, 오답…], 해설]`이고, 넷째 값 `1`이 붙으면 도전 문제입니다. 빈칸은 `___`, 빈칸이 둘이면 정답을 `…`로 나눠 적습니다.
- **답안 저장.** 페이지가 localStorage `soda-zus-NN`(`{v:1, t, m:{…}}`)에 바로 저장합니다. 문항 이름은 문항 내용으로 만든 값이라, 문항을 빼거나 새로 넣어도 남은 문항의 답은 이어지고, 내용을 고친 문항만 새 문항으로 시작합니다. 「전체 답 초기화」는 답만 지우고 스피드 퀴즈 최고 기록은 남깁니다. 학습 저장(`sync.js`)이 서버로 올리고, `autosave.js`가 기기 안에 복제본을 두고 「답안 백업」 단추를 붙입니다. 연습문제(`soda-ueb-NN`)와 과제의 저장 이름은 바뀌지 않았습니다.
- 페이지를 열고 브라우저 콘솔에서 `__sodaZusatz()`를 실행하면 그 페이지의 저장 이름과 저장 상태를 볼 수 있습니다.
