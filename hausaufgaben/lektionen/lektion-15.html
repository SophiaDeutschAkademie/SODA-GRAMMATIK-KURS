01

Schritt 1

Verstehen · 이해

교재를 보지 않고 직접 규칙을 발견하는 단계입니다.

복습1과: 4격(den Mann). 10과: 과거분사. 15과: "누가 했나"보다 무엇이 당했나에 초점 — werden + 과거분사!

1A. 관점 뒤집기 — 능동 4격 → 수동 1격

능동의 4격 목적어가 수동의 주어(1격)로 올라갑니다. 빈칸을 채우세요.

구분문장초점 능동Der Arzt operiert den Mann.den Mann = 격 수동 Mann wird operiert.주어 = 격

→ 능동의 4격 목적어가 수동의 격 주어가 되고, 동사는 로 바뀐다.

1B. werden + 과거분사 괄호 + 행위자

werden은 두 번째, 과거분사는 맨 끝. 행위자는 von/durch로. 채우세요.

Das Auto repariert. (차가 수리된다 — 현재)

사람 행위자: vom Arzt = + 3격. 수단·원인: + 4격 (durch das Feuer).

→ 행위자는 생략 가능. 사람은 +3격, 수단은 +4격.

1C. 수동의 시제 — werden만 바꾸면 됨

과거분사는 고정, werden 부분만 시제로 변신. 채우세요. (Das Auto … repariert)

시제werden 부분완성형 현재Das Auto wird repariert. 과거Das Auto wurde repariert. 완료 … Das Auto ist repariert worden.

→ 완료 수동의 끝은 ! "되다"의 완료 과 구분.

1D. 동작이냐 상태냐 — wird vs ist

werden 수동은 동작·과정, sein+과거분사는 상태. 채우세요.

Die Tür geschlossen. (닫히는 중 — 과정수동)

Die Tür geschlossen. (이미 닫혀 있다 — 상태수동)

→ 과정수동은 , 상태수동은 로 시작한다.

1E. 화법조동사 + 수동 · 3격 동사 수동

"~되어야 한다"는 조동사+과거분사+werden(원형). 3격 동사는 3격 유지. 채우세요.

Das Auto muss repariert . (수리되어야 한다)

능동 Der Arzt hilft dem Mann → 수동 Mann wird . (helfen 3격 유지)

→ 조동사 수동의 맨 끝은 과거분사+(원형). 3격 동사는 수동에서도 격.

참고수동을 대신하는 표현 sich lassen + 원형 = "~될 수 있다". Das lässt sich machen. = Das kann gemacht werden. (읽기 3A·말하기에 나옵니다)

1F. 핵심 규칙 자기 정리

  1. 수동은 능동의 격 목적어를 격 주어로 뒤집는다.

  2. 수동은 + 과거분사로 만들고, 과거분사는 맨 에 온다.

  3. 현재 , 과거 , 완료는 ist….

  4. 행위자(사람)는 +3격, 수단은 +4격이다.

  5. 상태수동은 +과거분사, 3격 동사는 수동에서도 격 유지.

2C. 행위자 — von vs durch

사람·주체는 von+3격, 수단·원인은 durch+4격. 알맞은 전치사를 쓰세요.

  1. Der Mann wird Arzt operiert.

  2. Die Stadt wurde das Feuer zerstört.

  3. Das Bild wurde Picasso gemalt.

  4. Das Haus wird den Sturm zerstört.

  5. Das Buch wurde dem Lehrer geschrieben.

  6. Der Brief wurde einen Boten gebracht. (사람이지만 전달 '수단·매개' → durch)

2D. 화법조동사 · 3격 동사 · 상태 수동

알맞은 수동 형태로 채우세요. (조동사 수동·3격 유지·상태수동에 주의)

  1. Das Auto muss repariert . (수리되어야 한다)

  2. Das gemacht werden. (될 수 있다 — können)

  3. Mann wird geholfen. (그 남자가 도움받는다 — helfen 3격)

  4. Helfern wird gedankt. (돕는 이들에게 감사한다 — 복수 3격)

  5. Die Tür geschlossen. (닫혀 있다 — 상태수동)

  6. Die Tür geschlossen. (닫히는 중 — 과정수동)

2E. 오류 찾기 — Fehlersuche

바르게 고친 것을 고르고, 오류 유형도 고르세요.

    ⊞ 유형:

4C. 누가 하나? 하는 중? 된 상태? — 수동태로 뜻 판단하기

▶를 눌러 문장을 듣고, 뜻에 맞는 것을 고르세요. 문장은 정답 보기를 누른 뒤에 나타납니다. 필요한 만큼 다시 들어도 됩니다.

Tip수동태에서 맨 앞 명사는 당하는 쪽입니다. 하는 사람은 von (vom) 뒤에 나옵니다. wird + 과거분사 = 지금 되는 중(동작), ist + 과거분사 = 이미 된 상태입니다. 정답 보기를 누르면 뜻을 알려 주는 말에 색 밑줄이 표시됩니다.

Beispiel · 예시

Das Kind wird vom Lehrer gefragt. → 선생님이 아이에게 묻는다.

맨 앞의 das Kind 는 질문을 받는 쪽입니다.

Das Auto ist repariert. → 차가 다 고쳐져 있다.

ist + 과거분사 = 이미 된 상태입니다.

    →

  6. 여기선 영어를 쓴다. (현재 수동)

    →

7B. 새 동사 한→독 번역

수동태로 시제·종류를 맞춰 쓰세요.

  1. 집이 지어진다. (현재) bauen → gebaut

    →

  2. 문이 열렸다. (과거) öffnen → geöffnet

    →

  3. 그 학교는 1950년에 설립됐다. (과거) gründen → gegründet

    →

  4. 집이 지어졌다. (완료) bauen → gebaut

    →

  5. 그 집은 지어져야 한다. (화법조동사) bauen → gebaut

    →

  6. 문이 열려 있다. (상태) öffnen → geöffnet

    →

  7. 그 가게는 그 남자에 의해 닫힌다. (행위자) schließen → geschlossen

    →

7C. 새 동사 오류 수정

바르게 고친 것을 고르세요.

  1. ✕ Das Haus ist gebaut geworden. (완료 수동)

    →

  2. ✕ Die Tür wird durch den Mann geöffnet. (사람 행위자)

    →

  3. ✕ Das Haus muss werden gebaut. (지어져야)

    →

  4. ✕ Das Haus wird gebaut worden. (현재 수동 의도)

    →

  5. ✕ Die Schule wurde 1950 gegründet worden. (과거 수동)

7D. 문법 핵심 빈칸

  1. 수동은 능동의 격 목적어를 격 주어로 뒤집는다.

  2. 수동은 + 과거분사로 만들고, 과거분사는 맨 에 온다.

  3. 현재 , 과거 , 완료는 ist….

  4. 행위자(사람)는 +3격, 수단·원인은 +4격.

  5. 상태수동은 +과거분사, 3격 동사는 수동에서도 격 유지.

지시 자기 평가 · Selbstbewertung

자신 있으면 O, 아직 불안하면 △, 모르겠으면 X를 누르세요.

문법 이해

수동 = 관점 뒤집기 + werden + 과거분사임을 안다.

현재(wird)·과거(wurde)·완료(worden) 시제를 안다.

행위자 von+3격, durch+4격을 안다.

상태 수동(ist)과 과정 수동(wird)을 구분한다.

화법조동사 수동과 3격 동사 수동을 안다.

단어

수동의 시제별 형태를 외웠다.

완료 수동이 worden임을 안다.

실전 적용

능동을 수동으로 전환할 수 있다.

수동의 시제를 바꿀 수 있다.

한국어를 보고 수동 문장을 쓸 수 있다.

새 동사에도 수동 규칙을 적용할 수 있다.
